# kOMA Plasma style

Derived from the locally installed Gradient-Dark-Plasma 12.6 by l4k1.
Upstream: https://github.com/L4ki/Gradient-Plasma-Themes
Original AUTHORS and LICENSE are retained. Assets retain their original licenses.

kOMA changes: package name/id and version; omitted the fixed `colors` file so
Plasma follows the system color scheme. Geometry and transparency are retained.

Panel customization: 40% background opacity (60% transparent), with the existing
1 px edge geometry colored using ColorScheme-Highlight. Applied to standard,
solid, opaque, and translucent assets; preserves rounded corners and masks.
