Bundled upstream release 1.6.5, unchanged SVG source archive.

Author source profile: https://bitbucket.org/dirn-typo/

License: GPLv3, as declared by the upstream Store listing (gplv3 tag).
See GPL-3.0.txt. The SVG source is included in the archive, not just rendered icons.

Verify with `sha256sum -c plasma-monochrome-icons.tar.gz.sha256`.
The installer installs this archive as plasma-monochrome-icons and adds these notices.
Papirus-Dark is required as the principal fallback; install the distribution's
papirus-icon-theme package before running the theme installer.
